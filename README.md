
# 🏠 HomeSmart — Smart Home Landing Page

A modern, fully responsive landing page for a smart home company, built with **HTML**, **Tailwind CSS v4**, **JavaScript**, and **Vite**.

---

## ✨ Features

- 🎨 **Modern UI** — Clean, utility-first styling with Tailwind CSS
- 📱 **Fully Responsive** — Optimized for mobile, tablet, and desktop
- 🍔 **Mobile Menu** — Hamburger menu with smooth toggle
- 🎯 **Smooth Scroll** — Anchor links scroll smoothly between sections
- 📝 **Contact Form** — Styled form with focus states and validation
- 🎬 **Hover Effects** — Cards lift on hover, buttons change color
- ⚡ **Tailwind CSS v4** — Latest version with Vite plugin
- 🚀 **Vite** — Lightning-fast dev server and build tool
- 🌈 **Custom Theme** — Amber & teal color palette
